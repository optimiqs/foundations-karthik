# Phase 0: Setup

**1 week · 30 Nov – 4 Dec**

## Goal

Be comfortable with the tools every engineer uses every day, and understand what happens when a browser talks to a server.

## Learn

| Type | Resource |
| -- | -- |
| Video | [Introduction to Programming and Computer Science](https://www.youtube.com/watch?v=zOjov-2OZ0E) (freeCodeCamp) |
| Video | [Git and GitHub for Beginners](https://www.youtube.com/watch?v=RGOj5yH7evk) (freeCodeCamp) |
| Course | [The Missing Semester](https://missing.csail.mit.edu/): lectures 1 (shell), 2 (shell tools) and 6 (version control) |
| Docs | [Pro Git, chapters 1–3](https://git-scm.com/book/en/v2) |
| Docs | [MDN: An overview of HTTP](https://developer.mozilla.org/en-US/docs/Web/HTTP) |

## Practise

- [ ] [Learn Git Branching](https://learngitbranching.js.org/): every level in "Introduction Sequence" and "Ramping Up"
- [ ] Install Node.js 24, pnpm, VS Code, Docker Desktop and Git
- [ ] Clone this repository, run `pnpm install` and `pnpm learn`, and see your first exercise
- [ ] Open a pull request that adds your first `LEARNING-LOG.md` entry

## Exit checklist

- [ ] I can create a branch, commit, push and open a pull request without notes
- [ ] I can explain what happens between typing a URL and seeing a page
- [ ] I can move around folders, create files and run programs in the terminal
