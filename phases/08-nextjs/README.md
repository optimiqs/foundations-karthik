**2 weeks · 12 Apr – 23 Apr**

## Goal

Build a web interface with React and Next.js on top of your capstone backend.

| Type | Resource |

## Project: clinic staff dashboard

- [ ] Sign in against your capstone API
- [ ] Today's appointments, with live updates when a patient confirms or cancels
- [ ] A patient page with their appointment and message history
- [ ] Loading, empty and error states on every page
- [ ] Works on a phone-sized screen

## Exit checklist

- [ ] Project merged and demoed
- [ ] I can explain: components and props, state, server and client components, how the dashboard gets live updates
