# Week 1: TypeScript

**30 Nov – 4 Dec**

## Goal

Be comfortable with your tools on day one, then write correct, readable TypeScript: types, functions, arrays and objects, generics, errors, async code, and a simple state machine.

## Day by day

| Day | Focus |
| -- | -- |
| Monday | Terminal, Git, GitHub, VS Code; install Node 24 and pnpm; clone this repository and open your first pull request |
| Tuesday | Variables, conditions, loops, functions, arrays, objects, strings |
| Wednesday | Types, interfaces, unions, narrowing, generics |
| Thursday | Errors, promises, `async`/`await`, JSON |
| Friday | State machines, catch-up, demo |

## Exercises

Run `pnpm learn`. It takes you through them in order.

| \# | Exercise | You practise |
| -- | -- | -- |
| 1 | `sum-of-evens` | Arrays, loops, `filter`, `reduce` |
| 2 | `word-count` | Strings, regular expressions, objects as maps |
| 3 | `phone-number` | Cleaning and validating US phone numbers |
| 4 | `group-by` | Generics and callbacks |
| 5 | `parse-appointment` | `unknown`, narrowing, result types |
| 6 | `retry` | `async`/`await` and errors |
| 7 | `chunk` | Slicing arrays, validating arguments |
| 8 | `unique-by` | `Set`, keeping order |
| 9 | `appointment-lifecycle` | A state machine: allowed moves, rejected moves |

## Exit checklist

- [ ] All 9 exercises pass
- [ ] I can branch, commit, push and open a pull request without notes
- [ ] I can explain a union type, a generic, what `await` does, and why a state machine rejects some moves
