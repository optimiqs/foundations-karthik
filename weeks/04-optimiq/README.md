# Week 4: Optimiq web

**21 Dec – 24 Dec**

## Goal

Run the Optimiq web app on your laptop, learn how the codebase is organised and what its rules are, and get your first real pull request merged.

## Day by day

| Day | Focus |
| -- | -- |
| Monday | Set up the codebase with your mentor; run the app; tour the folders |
| Tuesday | Read the repository guide with your mentor; pick your first issue |
| Wednesday | Build it; run lint, typecheck and tests before you push |
| Thursday | Review, fixes, merge; demo what you shipped |

Your mentor shares the repository access, the setup steps and your first issues on Linear.

## Exit checklist

- [ ] The web app runs on my laptop
- [ ] I can explain where routes, components, hooks and shared UI live
- [ ] My first pull request is merged
